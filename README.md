# Arhat Wear 👕🛍️

A fashion e-commerce website built using **HTML and CSS** as my first web development project.

Arhat Wear features a clean clothing-store layout with product displays, category navigation, a search bar, and a detailed footer. This project marks my first step into front-end web development and helped me practise structuring and styling webpages.

## ✨ Features

- **Navigation Bar:** Categories for Men, Women, Kids, Home, Beauty, Gen Z, and Studio.
- **Search Bar:** A search interface for products and brands.
- **Product Displays:** Product cards featuring fashion images, promotional text, and shopping calls to action.
- **User Interface:** Profile, wishlist, and shopping bag icons.
- **Footer Section:** Navigation links, an About Us section, and contact information.
- **Newsletter Section:** An email subscription form layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
